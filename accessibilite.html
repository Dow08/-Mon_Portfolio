Accessibilité

Déclaration d'accessibilité

Ce site vise la conformité WCAG 2.2 niveau AA. Cette page décrit ce qui est en place, ce qui a été vérifié et les limites connues. Dernière mise à jour : 13 octobre 2026.

Mesures en place

  • Structure sémantique : un titre principal, hiérarchie de titres, régions nommées, lien d'évitement vers le contenu.
  • Navigation entièrement utilisable au clavier ; indicateur de focus visible sur tous les éléments interactifs ; menu mobile avec état annoncé (aria-expanded), fermeture par Échap.
  • Contrastes de texte vérifiés sur les valeurs de la palette (minimum 4,9 : 1 pour le texte courant, la plupart au-delà de 6 : 1).
  • Respect de la préférence « réduire les animations » : aucune animation ni séquence pilotée par le défilement ; tout le contenu est affiché immédiatement.
  • Lecteur audio du flash info : bouton avec libellé, curseur de position utilisable au clavier, durée affichée.
  • Filtres de projets annoncés comme boutons à état (aria-pressed) ; mises à jour annoncées (aria-live).
  • Images et graphiques décoratifs masqués des technologies d'assistance ; la matrice de risques possède un titre et une description.
  • Texte redimensionnable, aucune information portée par la couleur seule, aucun contenu clignotant.
  • Aucune dépendance à un service tiers ; la page fonctionne sans JavaScript pour l'essentiel (les projets et le flash info nécessitent JavaScript ; un lien de repli vers GitHub est fourni).

Limites connues

  • Les titres et résumés du flash info sont traduits automatiquement : leur qualité linguistique n'est pas garantie.
  • Les descriptions de projets proviennent des fichiers README de GitHub et peuvent contenir des termes techniques non expliqués.
  • Le flash info audio n'a pas de transcription affichée ; le texte des articles résumés est disponible à côté du lecteur.
  • La séquence visuelle pilotée par le défilement est purement décorative ; son contenu n'est pas décrit car il ne porte aucune information.

Vérifications effectuées

Tests au clavier et sur six largeurs d'écran (320 à 1 440 px), audit automatisé (Lighthouse, axe-core) consigné dans le dépôt du site. Aucun test avec un lecteur d'écran n'a encore été réalisé : cette limite sera levée et cette page mise à jour.

Signaler un problème
